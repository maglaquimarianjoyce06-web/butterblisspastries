# Butter Bliss Bakery Website

Modern responsive bakery website based on the Butter Bliss business plan presentation.

## Included
- Pink / cream / dark green visual style inspired by the presentation
- Butter Bliss logo and bakery photos from the supplied presentation assets
- Responsive desktop and mobile layout
- Menu filters
- Functional shopping cart using localStorage
- Order inquiry form (front-end demo; connect to PHP/email for live submissions)
- Pricing and business information based on the supplied business plan

## Run
Open `index.html` in Chrome, Edge, or another modern browser.

## Folder structure
- index.html
- style.css
- script.js
- assets/
